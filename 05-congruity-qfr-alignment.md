# Congruity ↔ QFR Canonical Alignment

This document provides a semantic alignment between
the Congruity admissibility framework and QFR.

This is a **mapping of meaning**, not an integration of methods.

| Admissibility Framework | QFR Concept                    |
|-------------------------|--------------------------------|
| Admissibility           | Closure condition              |
| Boundary                | Recursive enclosure            |
| Constraint              | Invariance under recursion     |
| Coherence               | Self-consistent closure        |
| Stability               | Closed pattern persistence     |
| Collapse                | Loss of admissible closure     |

Both frameworks operate **before execution**,
at the level of what structures are allowed to exist.

No operational fusion is implied.
